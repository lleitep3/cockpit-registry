# Backend Development

Pacote para planejar e implementar APIs com fronteiras explícitas, Clean Architecture e testes orientados por comportamento.

## Conteúdo

- `skills/api-developer`: skill para planejar, implementar e revisar APIs.
- `skills/api-developer/references/clean-architecture.md`: referência de camadas, portas e testes.
- `skills/use-case-planner`: workflow para mapear fluxos de usuário e casos de uso antes do código.
- `skills/use-case-planner/references/use-case-planning-workflow.md`: formato reproduzível dos documentos entregáveis.
- `kb/guides/backend-development.md`: base de conhecimento reutilizável.

O pacote é agnóstico de framework, mas inclui orientação para Node.js, TypeScript e NestJS quando essa combinação for adequada.
